What's on air

The Wire is the free station. Bitcoin, Mining and Music are Pro in the Bitcoin Ticker apps.

Four hosts, real shiftsMarcus, Dana, Theo and Rae: a 30-minute shift each, idents, hand-offs and the small human beats between reads.
News as it breaksBitcoin and mining stories written into briefs the moment they land, retold three ways so a story never sounds the same twice.
The network, liveEvery block as it lands, fees, difficulty and the halving clock, read with the figures of the minute.
The Bitcoin Mining Guide, toldEvery article of the magazine as a feature, placed in its time; hundreds of one-line reads behind them.
This day in BitcoinDated history every day, the date spoken; Genesis Block Day, Pizza Day and the halving anniversaries celebrated on air.
Trivia every 20 minutesA question, the sting, the answer: Bitcoin, mining and the network, never the same question twice in a day.
Original musicSongs and transitions made for the station, levelled and trimmed, a featured track to open every session.
Karaoke wordsIn the apps, every read is shown word by word as it is spoken; the web player keeps to the title and the host.

Embed it

Paste the script once, then place <bitcoin-radio> wherever the player should sit: a top nav, a sidebar, a footer, a kiosk screen. Every player on a page shares one stream.

1 · Any web page 
<!-- once, anywhere in the page -->
<script src="https://bitcointicker-radio.yellow-glade-3f5f.workers.dev/embed.js" async></script>

<!-- the player, wherever it should sit -->
<bitcoin-radio></bitcoin-radio>
2 · Options 
<bitcoin-radio layout="bar" theme="auto" accent="#f7931a" label="Bitcoin Radio"></bitcoin-radio>
layoutbar · card · minibar is the nav pill; card adds the meter and credit; mini is the button alone.
themeauto · dark · lightauto follows the visitor's system setting.
accentany CSS colourThe play button and the meter. Default is Bitcoin orange.
labeltextThe name on the pill. Default "Bitcoin Radio".
3 · No scripts allowed? Use the iframe 
<iframe src="https://bitcointicker-radio.yellow-glade-3f5f.workers.dev/embed?layout=bar&theme=dark"
        width="340" height="56" style="border:0" allow="autoplay" title="Bitcoin Radio"></iframe>
4 · Your own buttons (apps, kiosks, React, anything) 
// the same engine, no UI: drive it from your own controls
BitcoinRadio.play();  BitcoinRadio.pause();  BitcoinRadio.skip();
BitcoinRadio.on('segment', s => console.log('on air:', s.title, s.hostName));
BitcoinRadio.state   // { playing, now, host, queue }

// native apps: the station is an open JSON API
GET  https://bitcointicker-radio.yellow-glade-3f5f.workers.dev/v1/radio/wire/playlist?listener=<id>&session=<nonce>
// each segment carries an audio URL; play them in order, POST the ids you played to /v1/radio/played
